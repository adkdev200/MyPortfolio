03 FIELD NOTES
NOTE / 001

The feedback loop is the product.

For computer-use agents, acting is only half the job. The system has to observe what changed and know when to try a different path.

2026 computer use
NOTE / 002

Fallbacks are a feature.

Good automation does not depend on one perfect interface. Accessibility data, OCR, vision, and input controls each cover a different failure.

2026 MCP
NOTE / 003

Autonomy needs memory.

Long-running agents become useful when they can preserve context, schedule the next step, and report what they did along the way.

2026 orchestration
